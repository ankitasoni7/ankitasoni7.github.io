# Mid-fidelity screens — project1

Drop your **mid-fidelity** phone screens here, named:

```
screen-01.png
screen-02.png
screen-03.png
```

They are referenced by `WireframeMorph.jsx` at:
`/projects/project1/mid-fidelity/screen-0N.png`

Tips:
- Portrait images (roughly 600×1300 / 9:19.5) look best in the iPhone frame.
- Until a file exists, the component falls back to a placeholder image automatically.
- Add more projects by copying this folder as `project2`, `project3`, … and passing
  `<WireframeMorph project="project2" />`.
